# MVP-MARTHAKAYKYMIRELLA

Projeto frontend em React + Vite para análise de notícias e checagem de confiabilidade.

## Como rodar

1. Instale as dependências:
   npm install
2. Inicie o servidor de desenvolvimento:
   npm run dev
3. Para gerar a build de produção:
   npm run build

## Observações

- O projeto compila corretamente com Vite.
- O README anterior tinha um conflito de merge que foi resolvido.
- Recomendado verificar também as dependências com `npm audit` para tratar vulnerabilidades reportadas.
